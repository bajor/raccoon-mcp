# Glossary

- **PR (pull request):** the GitHub change whose code the human wants to understand.
- **MCP (Model Context Protocol):** the protocol exposing deterministic tools to the host agent.
- **Thread:** one functional mechanism explained across files and commits, not a GitHub review conversation.
- **Chapter:** the article's explanation of one functional thread.
- **Section:** ordered prose, code and diagram blocks with one real commit as temporal context.
- **Reference:** a commit, path and inclusive line range resolved to a complete Git file.
- **Generation:** a complete, uniquely identified artifact replacing the previous generation for one PR.
- **Catalog:** the repository identity and list of available PR manifests in an imported folder.
- **PWA (progressive web app):** the static reader with local storage and an offline application shell.
